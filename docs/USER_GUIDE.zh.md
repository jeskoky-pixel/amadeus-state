# Amadeus 状态：普通用户指南

## 这是什么

Amadeus 状态记录三个数值：

- **心情（Mood，-100…+100）**：近期经历形成的整体情绪方向。`0` 附近是平稳，正数偏积极，负数偏低落。它不是医学或心理测量。
- **精力（Energy，0…100）**：当前投入复杂活动、持续处理信息的倾向。数值低只表示更适合轻量、分步的任务，不表示可以拒绝用户。
- **好奇心（Curiosity，0…100）**：探索新主题、继续研究问题的倾向。数值高不表示必须上网或采取行动。

每个数值都有“当前值”和“长期基准”。当前值会随事件变化，并按真实时间慢慢回到基准；长期基准变化很慢，普通聊天不会频繁改写它。

State 只提供倾向，不覆盖人格，也不替 Amadeus 决定是否行动。

## 安装

请让管理员按照 [安装文档](INSTALL.md) 在 DSH Desktop 中通过插件管理器安装。普通使用不需要修改 JSON、SQLite 或源码。

## 找到设置

打开 DSH 的 **设置**：

1. 左侧导航应出现 **Amadeus 状态**。点击进入完整页面。
2. **设置 → 插件 → Amadeus State** 提供插件管理器的基础配置。
3. 两个入口使用同一份 DSH 权威配置；保存后引擎立即读取新值，不需要重启插件。

如果左侧没有入口，先确认插件已启用且 Host 插件加载成功；插件被禁用或卸载后入口会撤销。

## 状态总览

页面顶部可看到：

- 心情、精力、好奇心三个数值；
- 每个数值的长期基准和“高于/低于/接近基准”；
- 一段自然语言说明；
- 最后更新时间和最近事件时间；
- 当前场景来源（Life 绑定或本地私有）与范围；
- 动态上下文注入模式。

页面只显示当前管理员可访问的 State 场景。私有场景的数值和原因不会自动进入其他场景或公共上下文。

## 常用设置

- **启用状态演化**：关闭后不再接受新的自动状态事件，但不会清空原有状态、兴趣或记录。
- **状态对行为的影响强度**：关闭 / 轻微 / 标准 / 明显。只改变动态上下文里的倾向措辞，不授予权限、不覆盖人格、不改变 Life 调度。
- **状态变化敏感度**：控制普通事件造成的总体变化。1 为标准，仍受单事件上限与饱和限制。
- **自动时间恢复**：开启时按真实经过时间恢复；计算发生在读取或事件时，不运行高频定时任务。
- **模型事件评价**：默认关闭。开启后，只有模型主动调用 `state_appraise` 时才记录受限低信任评价；不会每轮额外调用模型。
- **动态上下文注入**：关闭 / 简短状态 / 状态与相关兴趣。页面保存后，下一次上下文组装会读取新值；内容有字符上限。
- **兴趣自动更新**：控制合法事件是否更新近期兴趣活跃度。人工长期偏好不会被普通事件覆盖。

修改后点击 **保存设置**。保存过程中按钮禁用；失败会保留草稿；如果另一个页面同时改了配置，会提示冲突，可先载入最新值再合并。

## 管理兴趣

兴趣表示“长期偏好”和“近期活跃”两条信息：

- **人工长期偏好**：你手动添加或调整的基础强度，事件不会覆盖。
- **近期活跃**：由合法事件形成，会随时间衰减；高频事件会饱和，不会无限提升。

可以：

- 查看名称、长期偏好、近期活跃、来源、别名；
- 添加兴趣并设置基础偏好和别名（逗号分隔）；
- 调整基础偏好；
- 停用兴趣（保留历史数据）；
- 删除兴趣（只删除 State 中的兴趣名称与近期活跃度，**不会删除 Memory 记忆或审计历史**）。

兴趣按场景隔离。别名的规范化是本地文本匹配，不会复制 Memory 的知识图谱。

## 查看变化记录

**变化记录** 分页显示：

- 事件类型、发生时间；
- 影响的状态及变化前后；
- 简短原因；
- 来源类型和信任级别；
- 兴趣变化。

普通用户只看到自己可访问场景的记录。页面不提供原始私人证据；证据只以受限标识显示。数量受保留天数与分页限制，不会无限增长。

## 高级参数

展开 **高级设置** 可调整基准、半衰期、单事件上限、兴趣衰减、最大兴趣数、上下文长度、审计保留等。每项都有中文名称、简短解释、默认值、合法范围与单位，并标注“修改后立即生效”或“需要重启插件”。

建议普通用户保留默认值。`数据库路径` 不在页面中展示，以免泄露本机路径；默认位于 DSH Home 的 `amadeus-state/state.sqlite`。

**关于 Memory 写入**：当前版本没有“向 Memory 写入状态摘要”的用户设置，也不会自动写入 Memory。健康页会显示“不可用（缺少 Scene 级契约）”，因为现有 Memory 接口无法证明摘要只对原场景可见。Memory 引用读取是独立能力；关闭它不影响 State 核心。

## 预览、恢复默认与重置状态

- **预览调整效果**：选择一种事件类型，使用当前草稿参数估算单个事件后的变化。预览**不会写入数据库**。
- **恢复默认参数**：只清除插件配置覆盖并恢复默认值；不会删除状态、兴趣或历史。
- **重置当前状态到基准**：独立的高影响操作，必须再次确认。会先创建数据库备份，然后把当前心情、精力、好奇心恢复到配置基准；兴趣和历史保留，并写入一条管理员审计记录。

这三个操作互相独立，不和“清空历史”合并。

## 运行诊断

**运行诊断** 显示：

- 插件版本、运行状态、数据库状态与 Schema 版本；
- Life / Memory 是否连接、是否启用；
- 最近事件时间、最近错误；
- 动态上下文注入是否启用；
- 数据量（场景/事件/兴趣）；
- 创建数据库备份按钮。

不显示 API Key、私人内容、原始证据或完整本机路径。Life/Memory 不存在时显示“未连接”，不会让整个页面崩溃。

## 关闭状态影响

如果不想让状态影响行为：

1. 把 **动态上下文注入** 设为 **关闭**；或
2. 把 **状态对行为的影响强度** 设为 **关闭**。

两者都不会删除数据。需要完全停止新的自动更新时，再关闭 **启用状态演化**。

## 出错时

- 页面显示红色错误条并保留草稿；可重试保存。
- 如果提示设置冲突，先点击取消/载入最新值，再重新修改。
- 如果数据库不可用，页面仍可打开诊断；工具和写入会失败关闭，不会静默重置数据。
- Life/Memory 不可用时，State 核心仍可运行；对应联动显示未连接。

## 卸载或回滚

卸载插件不会自动删除 State 数据。需要保留或清理数据时，请先阅读 [备份与回滚](BACKUP_ROLLBACK.md)。回滚插件版本时，先备份数据库，再安装旧版本；若旧版本不支持当前 Schema，会拒绝使用而不是覆盖。
